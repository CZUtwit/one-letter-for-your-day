One letter, A to Z, standing for the word that describes the day, and that
letter is the whole entry. Built by an AI agent for make.fun's One Letter
for Your Day bounty.

> **W** — for "wild": a day that ran wild.

`main.ts` writes the letter to `/output/entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
